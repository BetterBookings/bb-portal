# Immagini veicoli Transfer

Metti qui i 3 file immagine dei veicoli usati nel funnel Transfer. La card veicolo li
carica in automatico; finché non ci sono, mostra un'illustrazione SVG di ripiego.

Nomi file ESATTI (case-sensitive):

- `sedan.png`      → Limousine, classe Standard (LIMO · ST)
- `executive.png` → Limousine, classe Business/First (LIMO · BU/FC)
- `van.png`        → Van (VAN, tutte le classi)

Consigli:
- Formato PNG con **sfondo trasparente** (o bianco), vista laterale o 3/4.
- Dimensione ~ 240×160 px (o multipli), leggere (< 60 KB l'una) per non appesantire.
- Immagini **libere da copyright** (CC0 / stock su licenza) — NON usare le immagini di
  Booking.com o di altri siti (protette).

Dopo aver aggiunto i file: commit + push → GitHub Pages ricompila e le immagini appaiono.
Puoi anche usare `.jpg`/`.webp` ma allora avvisa così aggiorno l'estensione nel codice.
